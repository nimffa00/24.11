# Місія 04 — стартовий проєкт «Шкільна їдальня 2.0»

Збережено вихідний дизайн, асинхронне завантаження меню та імітацію помилки. Додано готові елементи чотирьох фільтрів і 12 умовних страв.

## Фільтри меню
Після завантаження меню доступні живий пошук за назвою, фільтри категорії та максимальної ціни, а також відбір вегетаріанських страв. Умови можна комбінувати; кнопка скидання повертає всі фільтри до початкових значень.

## Запуск
У папці `canteen-demo` виконайте `python -m http.server 8000`, відкрийте `http://localhost:8000/`.

## Перевірка
Після завантаження меню перевірте пошук, категорію, максимальну ціну, вегетаріанські страви, поєднання умов, скидання та повідомлення про відсутність збігів.

Усі дані навчальні. Серверного API немає.
